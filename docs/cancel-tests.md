# Cancel and resume: manual test protocol (Extension Development Host)

Goal (rubric A3): Stop is instant and the workspace is consistent afterwards, whatever the run was doing; a dropped stream resumes.
Setup: `cd forge-agent && npm run build`, F5, open a CLEAN Flask 3.1.3 checkout (not `fixtures/flask`; run `git status` there first, it must be clean). TrueForge running with the usual `OUTBOUND_URL_ALLOWED_HOSTS`. Setting `forge.rollbackOnCancel` = true unless a case says otherwise. Open Output -> "Forge" and "Forge: Terminal".
Prompt used unless stated (Task B): *Add a built-in CLI command `flask config` that prints the app config as JSON, masking the value of any key containing SECRET, PASSWORD, TOKEN, or KEY as "***". It must appear in `flask --help`, have a test, and be documented with the other built-in commands.*
After EVERY case run `git status --porcelain` in the checkout (expected: empty after a rollback) and `git stash list` (expected: empty). Between cases: `git checkout . && git clean -fd` ONLY in your scratch checkout.

Pass criteria that apply to every case: the status line shows **"Stopping…" immediately** (stopwatch: < 0.2 s after the click) and then "Stopped"; the Stop button is disabled while stopping; the next message can be sent afterwards.

| # | Case | Steps | Expected | Result (PASS/FAIL, notes) |
|---|---|---|---|---|
| 1 | Cancel while streaming text | Send the prompt. While the first assistant text is streaming (before any tool card), press Stop. | "Stopping…" at once, then "Stopped". No more text appears afterwards. Notice: "Cancelled. Nothing had been changed." `git status` empty. | |
| 2 | Cancel while a diff is open | Send the prompt; wait for the first "Review diff", open it, do NOT accept. Press Stop in the panel. | Diff tab closes by itself, the Review queue entry turns "cancelled", nothing written (`git status` empty), the proposal text is gone from the editor. | |
| 3 | Cancel between approve and apply | Open a diff, click Apply and press Stop in the same second (repeat up to 5 times; the window is tiny). | Either outcome is correct and consistent: (a) Stop first: nothing written; (b) apply first: the file is written atomically and then rolled back. Never a half-applied file. Final `git status` empty. | |
| 4 | Applied edit rolled back | Accept all hunks of the first file (e.g. `src/flask/cli.py`), let the agent continue to the second review, then press Stop while that diff is open. | Notice "Cancelled. Rolled back 1 file from this run: src/flask/cli.py". `git status` empty; `git diff` empty. | |
| 5 | Rollback off | Set `forge.rollbackOnCancel` to false. Repeat case 4. | Notice "Cancelled. 1 applied file kept (rollback on cancel is off): src/flask/cli.py". The file keeps the accepted change. **Run "Undo run" afterwards**: it restores the file. Set the setting back to true. | |
| 6 | You edited the file after Forge | Accept the first file's hunks. Before pressing Stop, type a line of your own into that same file (do not save elsewhere). Press Stop. | The file is NOT overwritten: it still contains your line. Warning: "Left as you edited them (changed after Forge wrote them): src/flask/cli.py". | |
| 7 | Cancel while `run_command` runs | Send: *Run `sleep 120` with run_command and tell me when it ends.* Allow the command. While it runs press Stop. | Within ~2 s `ps -axo pid,command \| grep "sleep 120"` shows nothing (process tree killed). Terminal channel shows `[cancelled, killed in …s]`. | |
| 8 | Cancel while awaiting approval | Send the prompt of case 7 and leave the command card pending. Press Stop. | The command card disappears/greys out, the run ends "Stopped", the command never runs (`ps` shows no sleep). | |
| 9 | Double cancel | Press Stop twice quickly (or Stop, then run "Forge: Stop" from the Command Palette). | One "Stopping…" -> "Stopped"; no error toast; no second rollback notice. | |
| 10 | Cancel after done | Let a run finish ("Done"). Press "Forge: Stop" from the Command Palette. | Information message "Forge: nothing is running."; state stays "Done". | |
| 11 | Late tool call after Stop | (Covered by unit tests: `test/cancelHandlers.test.ts`.) Manually: press Stop while the agent is mid tool call and watch for 30 s. | No file changes appear after "Stopped"; Output -> Forge shows `cancelled-run` for any late tool call. | |
| 12 | Provider hangs on cancel | While a run streams, freeze TrueForge: `kill -STOP $(lsof -ti :8790)`. Press Stop. Then `kill -CONT <pid>`. | UI reaches "Stopped" within ~1 s although TrueForge is frozen. Output -> Forge later logs `sessions.cancel(...) failed or timed out (ignored)`. | |
| 13 | Dropped stream, still running (resume) | `npx tsx scripts/flaky-proxy.ts --cut-after 4`; set `forge.trueforge.baseUrl` to `http://localhost:8791`; send the prompt. | After ~4 s the connection is cut; the run does NOT fail: Output -> Forge shows `stream interrupted after N events`, `turn still running; re-attaching after event N`, and the run continues to completion without repeated text. | |
| 14 | Dropped stream, already finished | Same proxy with `--cut-after 3` and a very short prompt ("Say hi"). | The run ends "Done" with the complete answer; Output -> Forge shows either a re-attach or `rebuilding the final state from its event log`. | |
| 15 | Dropped stream, cannot recover | Start the proxy, send a prompt, then stop TrueForge entirely (`Ctrl-C` in its terminal) before the cut. | Error state with the real reason (e.g. connection refused / status could not be read), not a vague message. Restart TrueForge afterwards. | |
| 16 | Inline edit Stop | Select `get_debug_flag` in `src/flask/helpers.py`, run "Forge: Edit Selection" with the Task A instruction. When the diff opens press the status bar item "editing… (click to stop)". | Same path: diff closes, status bar item disappears, message "Edit cancelled", `git status` empty. | |
