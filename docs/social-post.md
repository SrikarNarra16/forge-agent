## LinkedIn

Built **Forge** for the TrueFoundry Forge-a-thon (Techfest IIT Bombay): a VS Code coding agent whose agent loop runs on **TrueForge**.

- Select code, press a shortcut, describe the change: a per-hunk diff opens, nothing touches your files until you accept, and one Cmd+Z undoes it.
- Agent mode finds the files itself (BM25 context with reasons), edits several files, and asks before running commands.
- Provider down? The request continues on the next model, still through TrueForge. Stop is instant and leaves nothing half-applied.
- Editor capabilities are MCP tools; the TrueForge Sessions page shows every turn, approval and deferred tool load.
